Telegram Bot API

First, the thing that actually matters: The Telegram Bot API is free, HTTP-based and needs nothing but a token from @BotFather.

In practice that means: Create a bot in one message, then send and receive messages, create channels, and drive webhooks entirely over plain HTTPS. It is the cheapest 'social media' channel a self-publishing site can own, and this blog posts to it when a token is configured.

For a personal project or side business, this covers you without breaking a sweat.

  • Message @BotFather and /newbot to get a token
  • Send messages with POST /bot<token>/sendMessage
  • Optionally set a webhook with setWebhook for incoming events

Mastodon API

Worth spending ten minutes on: Mastodon's API is free and fully documented — any instance lets you register an app and post programmatically.

In other words: Create an app in your instance's developer settings, exchange it for a token, and the REST API handles statuses, follows and search. Because the whole platform is open source and federated, posting to it costs nothing and can point at an instance you run yourself.

Keep it this simple and you'll be ahead of most tutorials out there.

Bluesky At Protocol

Skip the fluff and start here: Bluesky runs on the open AT Protocol, whose public API is free — an account plus an app password is all a bot needs to post.

In other words: createSession returns an access token, and app.bsky.feed.post publishes a post. No middleman, no paid 'basic tier' for your own account's posting, and the protocol is openly specified so the implementation is boring in the best way.

The links in the sources section go straight to the primary docs.
