Telegram Bot API

First, the thing that actually matters: The Telegram Bot API is free, HTTP-based and needs nothing but a token from @BotFather.

The upshot: Create a bot in one message, then send and receive messages, create channels, and drive webhooks entirely over plain HTTPS. It is the cheapest 'social media' channel a self-publishing site can own, and this blog posts to it when a token is configured.

No signup wall, no credit card — just a README and some patience.

  • Message @BotFather and /newbot to get a token
  • Send messages with POST /bot<token>/sendMessage
  • Optionally set a webhook with setWebhook for incoming events

Bluesky At Protocol

The foundation looks like this: Bluesky runs on the open AT Protocol, whose public API is free — an account plus an app password is all a bot needs to post.

Concretely: createSession returns an access token, and app.bsky.feed.post publishes a post. No middleman, no paid 'basic tier' for your own account's posting, and the protocol is openly specified so the implementation is boring in the best way.

The links in the sources section go straight to the primary docs.

Mastodon API

Skip the fluff and start here: Mastodon's API is free and fully documented — any instance lets you register an app and post programmatically.

In practice that means: Create an app in your instance's developer settings, exchange it for a token, and the REST API handles statuses, follows and search. Because the whole platform is open source and federated, posting to it costs nothing and can point at an instance you run yourself.

If you only do one thing today, make it this one.
