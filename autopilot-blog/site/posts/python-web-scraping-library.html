Pytrends

Skip the fluff and start here: pytrends is an open-source Python client for Google Trends — free programmatic access to interest-over-time data.

In other words: It wraps the unofficial Trends API, so it can break when Google changes things, but it is the standard way to check whether a topic's interest is rising before you commit the blog to a topic family. Use it as a trend check, not a firehose.
